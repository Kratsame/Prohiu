# Prohiu

นโยบายความเป็นส่วนตัวของแอป ProHiu Page Poster

เผยแพร่ที่ https://kratsame.github.io/Prohiu/

## ไฟล์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | หน้าเว็บที่ GitHub Pages เสิร์ฟ (ไทย + อังกฤษ) |
| `privacy-policy.md` | ต้นฉบับ markdown ของเนื้อหาเดียวกัน |

## เปิด GitHub Pages

หลัง push ไฟล์แล้ว ไปที่ Settings → Pages ของ repo นี้

- **Source:** Deploy from a branch
- **Branch:** `main` / `(root)`

กด Save แล้วรอสักครู่ หน้าเว็บจะขึ้นที่ URL ด้านบน

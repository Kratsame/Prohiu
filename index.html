นโยบายความเป็นส่วนตัว — โปรหิว (ProHiu Page Poster)

ปรับปรุงล่าสุด: 17 กันยายน 2569

เกี่ยวกับแอปนี้

ProHiu Page Poster เป็นเครื่องมือภายในที่ใช้จัดการและเผยแพร่โพสต์โปรโมชั่นอาหารไปยังเพจเฟซบุ๊ก "โปรหิว" แอปนี้ใช้งานโดยเจ้าของเพจเท่านั้น ไม่ได้เปิดให้บุคคลทั่วไปสมัครหรือเข้าใช้งาน

ข้อมูลที่เก็บ

แอปนี้ไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้ทั่วไป

ข้อมูลที่แอปประมวลผลมีเพียง:

  • เนื้อหาโพสต์ ที่เจ้าของเพจเป็นผู้ส่งเข้ามาเอง ได้แก่ ข้อความ ลิงก์ร้านอาหาร และรูปภาพประกอบ
  • โทเคนการเข้าถึงเพจ (Page Access Token) ที่ Meta ออกให้ เก็บไว้บนเซิร์ฟเวอร์ส่วนตัวเพื่อใช้เผยแพร่โพสต์
  • บันทึกการทำงาน (log) ของระบบ เช่น เวลาที่โพสต์ออกและผลลัพธ์ เพื่อการตรวจสอบและแก้ปัญหา

แอปไม่เก็บรวบรวมข้อมูลของผู้ที่เข้าชมเพจ ไม่เก็บรายชื่อผู้ติดตาม ไม่เก็บความคิดเห็น และไม่ติดตามพฤติกรรมผู้ใช้เฟซบุ๊กรายใด

การใช้ข้อมูล

ข้อมูลทั้งหมดใช้เพื่อวัตถุประสงค์เดียว คือการสร้างและเผยแพร่โพสต์ไปยังเพจเฟซบุ๊กของเจ้าของแอปเอง

ไม่มีการขาย ให้เช่า แลกเปลี่ยน หรือส่งต่อข้อมูลให้บุคคลที่สามเพื่อการโฆษณาหรือวัตถุประสงค์ทางการค้าใด ๆ

การเก็บรักษาและความปลอดภัย

ข้อมูลถูกเก็บไว้บนเซิร์ฟเวอร์ส่วนตัวที่เจ้าของแอปควบคุมเอง เข้าถึงได้เฉพาะผู้ดูแลระบบ

โทเคนการเข้าถึงถูกเก็บในไฟล์ตั้งค่าที่จำกัดสิทธิ์การอ่าน และไม่ถูกเผยแพร่ในโค้ดสาธารณะ

รูปภาพและร่างโพสต์จะถูกลบเมื่อไม่จำเป็นต้องใช้แล้ว

บริการภายนอกที่เกี่ยวข้อง

แอปเชื่อมต่อกับบริการต่อไปนี้เพื่อการทำงาน:

  • Meta Graph API สำหรับเผยแพร่โพสต์ไปยังเพจเฟซบุ๊ก อยู่ภายใต้นโยบายของ Meta
  • Anthropic Claude API สำหรับช่วยร่างข้อความโพสต์ เนื้อหาที่ส่งไปมีเพียงข้อมูลโปรโมชั่นที่เจ้าของเพจใส่เข้ามา ไม่มีข้อมูลส่วนบุคคล

สิทธิของผู้ใช้

เนื่องจากแอปไม่ได้เก็บข้อมูลส่วนบุคคลของบุคคลภายนอก จึงไม่มีข้อมูลให้ร้องขอเข้าถึงหรือลบ

หากมีข้อสงสัยเกี่ยวกับข้อมูลที่เกี่ยวข้องกับเพจ สามารถติดต่อได้ตามช่องทางด้านล่าง

การลบข้อมูล

เจ้าของแอปสามารถเพิกถอนโทเคนการเข้าถึงได้ทุกเมื่อผ่านการตั้งค่าเพจเฟซบุ๊ก ซึ่งจะทำให้แอปไม่สามารถเข้าถึงข้อมูลเพจได้อีก

ข้อมูลที่เก็บไว้บนเซิร์ฟเวอร์จะถูกลบเมื่อเลิกใช้งานแอป

การเปลี่ยนแปลงนโยบาย

หากมีการแก้ไขนโยบายนี้ จะปรับปรุงวันที่ด้านบนและเผยแพร่ในหน้าเดียวกันนี้

Privacy Policy — ProHiu Page Poster (English)

Last updated: 17 September 2026

About this app

ProHiu Page Poster is an internal tool used to compose and publish food promotion posts to the Facebook Page "โปรหิว" (ProHiu). It is operated solely by the Page owner and is not open for public registration or use.

Information collected

This app does not collect personal information from general users.

The only data it processes is:

  • Post content submitted by the Page owner, including text, restaurant links, and accompanying images
  • A Page Access Token issued by Meta, stored on a private server for the purpose of publishing posts
  • Operational logs such as publish timestamps and outcomes, used for auditing and troubleshooting

The app does not collect data about Page visitors, does not store follower lists or comments, and does not track any Facebook user's behavior.

Use of information

All data serves a single purpose: composing and publishing posts to the owner's own Facebook Page.

No data is sold, rented, exchanged, or shared with third parties for advertising or any commercial purpose.

Storage and security

Data is stored on a private server controlled by the app owner and is accessible only to the administrator.

The access token is kept in a permission-restricted configuration file and is never published in public code.

Images and post drafts are deleted once no longer needed.

Third-party services

The app connects to the following services to function:

  • Meta Graph API — to publish posts to the Facebook Page, subject to Meta's own policies
  • Anthropic Claude API — to assist in drafting post copy; only promotional information entered by the Page owner is sent, never personal data

User rights

Because the app collects no personal data from third parties, there is no personal data to request access to or deletion of.

For questions regarding Page-related data, use the contact channel below.

Data deletion

The app owner may revoke the access token at any time through Facebook Page settings, which immediately ends the app's access to Page data.

Data stored on the server is deleted when the app is decommissioned.

Changes to this policy

Any revision will update the date above and be published on this same page.
